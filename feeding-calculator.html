Feeding Calculator Platform

Multi-market delivery, product-data integrations, and production reliability for Hill’s Pet Nutrition.

Business outcome

  • Launched across 10+ international markets.
  • Scaled to 16k active feeding plans.
  • Reached 111% of the annual conversion target.

Architecture

A micro-frontend application supported by GCP / Cloud Run services. AEM provides product data through GraphQL and Stibo PIM through REST. Redis caches product data, and generated recommendations are persisted to Firestore.

Designed and won approval for an architecture to remove the product’s dependency on a legacy monolith and support independent regional scaling.

Reliability work

  • Changed the cache strategy and added payload-integrity checks.
  • Prevented scheduled refreshes from replacing valid Redis product data with corrupt or missing payloads.
  • Diagnosed and fixed production backend failures using Cloud Run logs and tracing across service boundaries.

Multi-market delivery

  • Implemented i18n across 10+ markets.
  • Feature-flagged Hill’s Pet versus Hill’s Vet experiences.
  • Feature-flagged Stibo versus AEM product sources.
  • Shipped through existing GitHub Actions CI/CD workflows.
  • Partnered with analytics teams to structure Google Analytics data.
